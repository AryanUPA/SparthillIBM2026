ABOUT & TRUST
Built for a clearer handoff.
CivicSignal helps prepare a resident controlled draft. It is a local hackathon prototype, not a San José government service.
01
What analysis does
Local demo rules suggest a category, ask focused questions, and flag possible gaps. An IBM Bob provider can replace this once its API contract is configured.
02
What routing means
The tracker assigns a likely San José department from a curated directory. Uncertain cases stay in Needs review. CivicSignal does not send reports to agencies.
03
How data is kept
Unsaved drafts stay in browser memory. Confirmed reports go to a local JSON file, visible through the password protected tracker. Exact addresses require separate consent.
